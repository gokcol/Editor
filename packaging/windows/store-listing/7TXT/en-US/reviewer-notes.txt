7TXT 1.0.4 / MSIX 1.0.4.0 — Windows 11 x64 desktop application.

No account or subscription is needed. No ads or in-app purchases. Core text editing works offline. The package uses Windows 11's system Evergreen WebView2 runtime.

Restricted capability: runFullTrust. This Tauri/Rust desktop editor uses native file dialogs, user-selected local files, clipboard operations, and draft recovery. It runs at the current user's privileges with standard MSIX virtualization.

Launch from Start, open a UTF-8 text file, edit Unicode text, and use Ctrl+S. Restart with an unfinished draft to verify recovery. Open a Markdown file and choose Preview > Edit. Right-click a table cell to insert a row or right-click a list item to indent it. Click a link to edit it, or use Ctrl+F to replace a phrase. Click Done to return to reading and save. The Open link action uses the system handler for web and email addresses.

Ask AI and native WebKit PNG/PDF export are macOS-only in this version. For update checks, choose Help > Check for Updates. Store-signed installations check Microsoft Store, and optional daily checks are off by default. Update checks keep documents and file paths on the device.

The upload uses the assigned Partner Center identity and the released 7TXT 1.0.4 Windows executable. Automated checks use a separate disposable package identity.
