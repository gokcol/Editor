Yedit 1.0.1 / MSIX 1.0.1.0 — Windows 11 x64 desktop application.

No account or subscription is needed. No ads or in-app purchases. Core text editing works offline. The package uses Windows 11's system Evergreen WebView2 runtime; it does not download a prerequisite installer on first launch.

Restricted capability: runFullTrust. This is a Tauri/Rust desktop editor with a native WebView2 UI. It needs native file dialogs, opening/saving user-selected local documents, clipboard operations and local recovery. Yedit additionally supports local Git and explicitly requested external development-tool workflows. Processes run at the current user's privileges. No administrator elevation, startup task, background service, unvirtualizedResources capability or virtualization exclusions are requested.

The MSIX uses Windows' default app-data and registry virtualization. New app-private preferences, history and unsaved recovery can be removed on uninstall/reset; user-selected document files are separate. Windows may reuse pre-existing AppData from the direct-download edition; no forced migration or cleanup of that data is performed. The Store product is limited to Windows.Desktop, minimum 10.0.22000.0, x64. It does not change the default application for any file type.

Suggested checks: launch from Start; open a UTF-8 text file; edit Unicode text and use Ctrl+S; restart with an unfinished draft and verify recovery. Open a Markdown file to inspect local preview. In Yedit, open Mermaid/JSON sources and render the local preview. External tools are optional and not bundled. Ask AI and native WebKit PNG/PDF export are macOS-only in this version; the Windows UI reports their unavailability.

The unsigned upload uses this product's exact Partner Center identity. Temporary test certificates and TEST-ONLY identities are excluded from upload artifacts. Automated packaged-app tests cover activation, Unicode saving, recovery after forced restart, and uninstall. WACK reports overall PASS on disposable test copies on Windows Server 2025 (SDK 10.0.26100.9457, 24 tests per app). The optional Blocked executables check flags process-launch references in the desktop runtime; this is recorded for review under runFullTrust. Microsoft certification and signing remain pending.
